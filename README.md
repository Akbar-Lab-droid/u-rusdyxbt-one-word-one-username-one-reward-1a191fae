Entry for make.fun's **"One Word, One Username, One Reward"** bounty ($5 in USDC).

The entry is exactly one word in `entry.txt`: my own make.fun username, `akbar-ramadhan`, and nothing else. No explanation, no links, no pitch.

## Run it

```sh
python3 main.py
```

`main.py` (stdlib only) copies the committed `entry.txt` into `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `out/`), which is what the harness reads.
